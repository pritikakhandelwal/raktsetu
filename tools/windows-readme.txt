RaktSetu for Windows
====================

Nothing to install: Java is included.

Web app
  Double-click RaktSetu.exe. A window opens showing the server's progress, and after
  about 20 seconds your browser opens http://localhost:8080. The first visit asks
  you to create the network administrator.
  Keep the window open while you use RaktSetu; close it to stop RaktSetu.
  Your data is kept in the RaktSetu\data folder in your user folder
  (for example C:\Users\<you>\RaktSetu\data). Delete that folder to start afresh.

Console app (the course V1)
  Double-click "RaktSetu Console.exe". It opens a 16-option menu on a sample network
  and keeps its data in a raktsetu-data folder next to the program.

If Windows SmartScreen warns about an unrecognised app, choose "More info", then
"Run anyway": the program is not signed with a paid certificate.

Source code, report and documentation: https://github.com/pritikakhandelwal/raktsetu
